### Kode Navigasi Terminal di Ubuntu

| No | Perintah | Fungsi |
| :---: | :--- | :--- |
| 1 | `ls` | Melihat daftar isi folder secara ringkas. |
| 2 | `ls -l` | Menampilkan isi detail folder: ukuran file sampai tanggal dibuatnya. |
| 3 | `ls -la` | Menampilkan file tersembunyi (file yang ada tanda titik di depannya). |
| 4 | `cd Documents` | Masuk ke dalam folder "Documents". Nama folder harus sesuai agar perintah berjalan lancar. |
| 5 | `cd ..` | Keluar dari folder sekarang dan balik ke folder sebelumnya (naik satu level ke atas). |
| 6 | `pwd` | Mengecek posisi folder saat ini, menampilkan alamat jalurnya agar tidak bingung berada di direktori mana. |
| 7 | `mkdir teknologi` | Membuat folder baru dengan nama "teknologi". |
| 8 | `mkdir it` | Menyiapkan folder "it" agar direktori sistem terlihat lebih rapi dan terstruktur. |
| 9 | `rm teknologi.txt` | Menghapus sebuah file bernama "teknologi.txt". |
| 10 | `rm -r it` | Menghapus sebuah folder dan seluruh isinya secara permanen. Tambahan `-r` wajib ada jika ingin hapus folder, bukan file biasa. |
| 11 | `mv so.txt informasi.txt` | Mengubah nama file dari `so.txt` menjadi `informasi.txt` tanpa mengubah isi filenya. |
| 12 | `mv sistemoperasi.txt teknologi` | Memindahkan file ke folder "teknologi". |
| 13 | `cd teknologi` | Masuk ke dalam folder teknologi untuk mengecek isi di dalamnya. |
| 14 | `cat informasi.txt` | Membuka, membaca, dan mengetahui isi dari file `informasi.txt` secara langsung dari terminal. |
