### Tahap Instalasi VirtualBox & Ubuntu

#### A. Tahap Instalasi Aplikasi VirtualBox

| No | Langkah | Keterangan |
| :---: | :--- | :--- |
| 1 | Buka situs resmi | Ketik pencarian untuk install VirtualBox di **virtualbox.org**. |
| 2 | Unduh installer | Unduh file ISO Ubuntu Desktop di VirtualBox, sesuaikan dengan sistem operasi yang digunakan (Windows). |
| 3 | Setup installer | Jika tampilan sesuai, lanjutkan setup install VirtualBox versi **7.2.6**, lalu klik **Next**. |
| 4 | License Agreement | Klik **"I accept the terms in the license agreement"**, lalu klik **Next**. |
| 5 | Pilih fitur & lokasi | Pastikan fitur **VirtualBox Application** dipilih, tentukan lokasi instalasi di `C:\Program Files\Oracle\VirtualBox\`, lalu klik **Next**. |
| 6 | Selesai | Menunjukkan VirtualBox versi 7.2.6 telah di-install oleh sistem, lalu klik **Finish**. |

#### B. Tahap Instalasi Sistem Operasi

| No | Langkah | Keterangan |
| :---: | :--- | :--- |
| 7 | Unduh Ubuntu | Buka situs resmi untuk install Ubuntu. |
| 8 | Buat mesin baru | Klik **"New"** di VirtualBox dan beri nama untuk sistem Ubuntu. |
| 9 | Status mesin | Setelah akun dibuat, tampilan berubah menjadi **Powered Off**. Klik panah hijau untuk memulai. |
| 10 | Buat mesin baru | Klik **"New"** dan beri nama untuk sistem GitHub. |
| 11 | Konfigurasi resource | Tentukan RAM (**4096 MB**), CPU (**1 CPU**), dan penyimpanan disk (**25 GB**), lalu klik **Next**. |
| 12 | Identitas pengguna | Tentukan username, kata sandi, dan nama host Ubuntu agar berjalan normal tanpa input manual. |
| 13 | Ringkasan | Menampilkan ringkasan keseluruhan pengaturan VirtualBox, termasuk lokasi penyimpanan ISO Ubuntu. |
| 14 | Mulai mesin | Setelah akun dibuat, status **Powered Off**. Klik panah hijau untuk memulai. |

#### C. Tahap Mengisi Identitas pada Mesin SO

| No | Langkah | Keterangan |
| :---: | :--- | :--- |
| 15 | Pilih bahasa | Pilih **"Bahasa Indonesia"**, lalu klik **Next**. |
| 16 | Aksesibilitas | Fitur bantuan seperti zoom untuk memudahkan user berkebutuhan khusus saat instalasi. |
| 17 | Tata letak keyboard | Memilih susunan karakter keyboard disesuaikan dengan kenyamanan bahasa. |
| 18 | Koneksi internet | Atur koneksi internet untuk pembaruan perangkat lunak. Klik **"Gunakan sambungan nirkabel"**, lalu klik **Next**. |
| 19 | Peramban web | Untuk memasang peramban web dan menghemat ruang penyimpanan. |
| 20 | Driver tambahan | Untuk memasang driver tambahan WiFi atau format agar perangkat keras berjalan optimal. |
| 21 | Partisi disk | Pilih **"Hapus disk dan pasang Ubuntu"**. |
| 22 | Identitas pengguna | Mengisi nama, jenis komputer, membuat username, dan kata sandi untuk keamanan. |
| 23 | Zona waktu | Pemilihan lokasi zona waktu sistem wilayah saat ini (**Lombok – Mataram**). |
| 24 | Ringkasan akhir | Menampilkan ringkasan akhir pengaturan instalasi. Tekan tombol **Pasang** untuk mengubah disk. |
| 25 | Proses instalasi | Sistem menyalin berkas Ubuntu ke dalam disk. Tunggu proses loading bar selesai. |
| 26 | Selesai | Ubuntu sudah di-setup dan siap digunakan. |
